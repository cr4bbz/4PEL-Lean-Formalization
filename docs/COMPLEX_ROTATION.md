# Complex Rotation: Making the Imaginary Unit Do Work

Status: `PROVED` / `GENERAL-THEOREM` for the exact Lean statements on
`research/complex-coordinates`.

Module: `PEL4/ComplexRotation.lean`. Root import: active.

## Why this module exists

`ComplexCoordinates.lean` originally used a coordinate pair without
multiplication. That was enough to place `T`, `F`, `B`, and `N` at
`1`, `-1`, `i`, and `-i`, but it left open whether `i` did more than name the
vertical axis.

`ComplexRotation.lean` installs Gaussian-integer multiplication and proves
that multiplication by `i` is the cyclic quarter turn of the four-valued phase
space. This is a symmetry of the coordinate geometry, not a new connective of
the object language.

## Verified results

### Coordinate algebra

```lean
theorem ComplexCoord.I_mul_I : I * I = negOne
theorem ComplexCoord.I_mul (z) : I * z = ⟨-z.im, z.re⟩
theorem ComplexCoord.iConjugate_eq_I_mul_conj (z) :
  iConjugate z = I * conj z
theorem ComplexCoord.negConjugate_eq_neg_conj (z) :
  negConjugate z = -(conj z)
```

Thus the two earlier coordinate actions are genuine complex operations once
multiplication and conjugation are present.

### Categorical rotation

```lean
def FDEValue.conflate (v) := ⟨!v.neg, !v.pos⟩
def FDEValue.rotate (v) := ⟨!v.neg, v.pos⟩
```

Lean verifies:

- conflation is complex conjugation in truth/information coordinates;
- `rotate` follows `T → B → F → N → T`;
- the rotation is multiplication by `i` and has order four;
- negation and conflation commute and compose to the half turn;
- the quarter turn is not one of the four transformations generated by
  negation and conflation;
- every quarter turn crosses exactly one threshold wall.

These results support a dihedral interpretation of the Belnap square. The
repository does not yet package the eight transformations as a formal `D₄`
group action, so that stronger statement remains a research target.

### Rotation of evidence profiles

For a normalized profile `(T,B,N,F)`, define

```text
rotate(T,B,N,F) = (N,T,F,B).
```

Then

```lean
theorem FourCellMass.cellBalanceCoord_rotate (s) :
  (s.rotate).cellBalanceCoord = I * s.cellBalanceCoord
```

The same module proves four linear inequalities placing every profile inside
the `l¹` diamond of radius `total`. This is a containment result. At fixed
natural total, not every lattice point in that diamond is necessarily
realizable; an exact image theorem requires parity and integrality conditions.

### Lossless extension

The complex coordinate retains two of the three degrees of freedom of a
normalized four-cell profile. The missing real mode is

```text
h = (T + F) - (B + N).
```

Lean proves

```text
4T = total + h + 2 Re(z)
4F = total + h - 2 Re(z)
4B = total - h + 2 Im(z)
4N = total - h - 2 Im(z).
```

Consequently `(total,z,h)` reconstructs the full profile, and rotation negates
`h`.

### Classifier equivariance

At the balanced threshold `2k = total`, the threshold classifier commutes with
one quarter turn provided `Im(z) ≠ Re(z)`. The excluded diagonal is substantive:
the classifier treats threshold equality as support, and this asymmetric tie
rule is not rotation-invariant.

## Verification boundary

- Complex multiplication is not an object-language logical connective.
- No quantum-probabilistic interpretation is asserted.
- The character-theoretic reading of `(total,z,h)` is interpretive rather than
  a separately mechanized representation theorem.
- A full formal `D₄` group action and the exact integer image of the simplex
  remain open.
