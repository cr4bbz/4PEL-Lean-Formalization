# Gate 23: recursive causal descent

## Research question

Can every recovery change be traced through the finite Gate-21 evaluation tree
to a reachable belief coordinate whose cumulative evidence scope strictly
shrinks?

## Answer

Yes, for one admissible conditionalization from a model whose local measures
are concentrated on the supplied cumulative scopes. Gate 22 proves that every
scope assignment generated by a preceding finite update prefix satisfies this
concentration premise.

The main result is:

```text
modal value changes at (w, phi)
->
there is a belief observation in recoveryObservationSites m w phi
whose cumulative scope shrinks strictly.
```

Combining this with Gate 21 yields:

```text
recovery changes on finite roots
->
some belief observation in the original finite compiler
has strict cumulative-scope shrinkage.
```

With `WorldListCovers`, the same conclusion holds for the repository's globally
quantified recovery predicate.

## How causal descent works

The proof follows the syntax of the changed modal formula:

- atomic values cannot change because conditionalization preserves valuation;
- a changed negation descends to its body;
- a changed conjunction implies that at least one conjunct changed;
- changed knowledge or raw possibility descends to a changed accessible body
  value because accessibility is unchanged;
- at a changed belief node, either its own scope shrinks strictly or Gate 22
  supplies a changed accessible body value and descent continues there.

Each recursive call uses a strict syntactic subformula. The proof therefore
terminates without an additional well-foundedness axiom.

## Compiler closure

The causal search may begin at a changed observation already located inside a
larger Gate-21 compiler. Gate 23 proves that the compiler is closed under the
compiled descendants of any site it contains. Consequently, the final strict
shrink witness remains a member of the original finite-root observation map.

## Trace form

For a finite dependent update prefix, Lean automatically uses the final
cumulative Gate-20 scope at every agent/world coordinate. Gate 22 supplies
concentration of the current posterior on those scopes. Hence every recovery
change at the next trace edge consumes a strict scope loss at a reachable
belief observation.

The concrete first loss of the Gate-19 `T -> N -> T` example is verified as an
instance of this general theorem over its twenty Gate-21 observation
positions.

## What remains for a numerical bound

Gate 23 establishes causal localization, but not yet trace-level counting. The
compiler retains duplicate observation positions, and the same agent/world
coordinate may occur through several syntactic paths. This does not prevent a
finite upper bound: summing Gate-20 budgets over all belief positions safely
overcounts duplicated resources. Deduplicating coordinates is needed only for
a sharper bound.

The next research question is:

> Can the number of recovery-changing edges in a finite update trace be
> bounded by the sum of Gate-20 scope budgets over the belief positions in the
> Gate-21 compiler?

Gate 24 should first prove this safe position-wise bound. A subsequent
coordinate quotient can sharpen it by removing duplicated budgets.
