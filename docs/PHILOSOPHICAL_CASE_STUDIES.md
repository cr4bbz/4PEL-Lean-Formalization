# Philosophical Case Studies in 4-PEL

This document turns the existing paradox modules into a research programme rather than a catalogue of examples.

## Method

Each case study should separate four layers:

1. **Object-level semantics** — which propositions receive positive and negative support?
2. **Epistemic policy** — which support levels cross the Lockean belief threshold?
3. **Aggregation principles** — which closure, consistency, or introspection rules are additionally imposed?
4. **Philosophical diagnosis** — which layer actually generates the paradoxical result?

The target is not merely to show that 4-PEL can represent a paradox.  The target is to identify assumptions that are necessary, sufficient, dispensable, or jointly responsible for the paradox.

The workflow mirrors the structural method used in `goedel-4pel`:

```text
informal paradox
      |
      v
signed / probabilistic reconstruction
      |
      v
assumption decomposition
      |
      v
finite models and countermodels
      |
      v
minimality / recovery questions
      |
      v
philosophical interpretation
```

## Case Study 1 — Preface Paradox

### Informal problem

A careful author believes every individual assertion in a book, while also believing, on the basis of ordinary fallibility, that at least one assertion in the book is false.

Let the representative claims be `p1`, `p2`, and `p3`.

The classical-looking pressure is:

```text
B(p1)
B(p2)
B(p3)
B(not (p1 and p2 and p3))
```

Together with conjunctive closure of belief:

```text
B(p1) and B(p2) and B(p3)
    -> B(p1 and p2 and p3)
```

this generates the familiar tension.

### 4-PEL control model

`PEL4/Paradoxes/Preface.lean` uses four equiprobable worlds:

```text
allCorrect : p1=T, p2=T, p3=T
error1     : p1=F, p2=T, p3=T
error2     : p1=T, p2=F, p3=T
error3     : p1=T, p2=T, p3=F
```

with Lockean threshold

```text
c = 3/4.
```

Hence every individual claim has positive probability `3/4`, but the conjunction has positive probability only `1/4` and negative probability `3/4`.

The intended evaluations are therefore:

```text
B(p1) = T
B(p2) = T
B(p3) = T

B(p1 and p2 and p3) = F
B(not (p1 and p2 and p3)) = T
```

The first philosophical result is therefore diagnostic rather than revisionary:

> Threshold belief alone does not generate an object-level contradiction.  The Preface pressure appears when local threshold acceptance is combined with a conjunctive closure principle that treats individually accepted claims as jointly accepted.

### Research hypotheses

#### H1 — Threshold-source hypothesis

The paradox is generated by Lockean threshold belief itself.

**Current control-model status:** disfavoured.  The threshold model produces local acceptance plus global fallibility without itself deriving belief in the conjunction.

#### H2 — Closure-source hypothesis

The paradox is generated by conjunctive closure of belief rather than by the threshold rule alone.

**Current control-model status:** supported by the first model.  The instantiated closure formula evaluates unsuccessfully while each local belief succeeds.

#### H3 — Rational-glut hypothesis

The correct representation of the Preface state is a four-valued epistemic glut.

**Status:** open.  The current model deliberately keeps the object-level valuation classical and therefore shows that a glut is not required merely to represent the Preface configuration.  A later model should test whether a glut becomes appropriate at a meta-level that records incompatible acceptance policies.

#### H4 — Two-kinds-of-incoherence hypothesis

4-PEL can distinguish:

```text
object-level inconsistency
```

from

```text
policy-induced / inferential incoherence.
```

**Status:** promising.  The current model realizes the second without the first.

## Next Preface experiments

### P1 — Threshold sweep

Generalize to `n` claims and vary `c`.

Question:

```text
for which n and c can every B(pi) hold
while B(p1 and ... and pn) fails?
```

This should yield an exact aggregation boundary.

### P2 — Error-distribution sweep

Replace the symmetric one-error worlds by arbitrary probability weights.

Question:

```text
which probability distributions preserve local acceptance
and global fallibility?
```

### P3 — Signed evidence

Introduce genuine `B` and `N` values at the object level rather than embedding a classical valuation into FDE.

Question:

```text
Does four-valued evidence enlarge the Preface region,
shrink it, or divide it into philosophically distinct subregions?
```

### P4 — Closure variants

Compare at least:

```text
full conjunctive closure
pairwise closure
bounded-k closure
closure only for independent claims
closure only above a stronger threshold
```

The research target is the weakest closure principle that recreates the contradiction pressure.

### P5 — Recovery theorem

Seek a theorem of the form:

```text
LocalAcceptance
+ ClosureCondition X
+ GlobalFallibility
-> epistemic conflict
```

and then prove countermodels when components of `X` are removed.

This is the direct analogue of the assumption-minimality method in `goedel-4pel`.

## Planned sequence

1. Preface — aggregation and fallibility.
2. Lottery — threshold belief and conjunction.
3. Fitch — knowability and modal collapse.
4. Moore — self-referential belief/content interaction.
5. Contrary-to-Duty — normative conflict and gaps/gluts.

The central criterion for success is always the same:

> A case study earns philosophical value only when the formal model reveals a distinction, dependency, boundary, or countermodel that is not already visible from the informal statement of the paradox.
