# Paper review after Gate 19

## Review target

This review compares manuscript version 0.13 with the formal development now
completed through Gate 19. It is a currency and claim-scope review, not an
independent external peer review.

## Overall judgment

The manuscript remains internally defensible but is now substantially behind
the Lean development. Its theorem narrative ends at Gate 9, whereas the active
branch contains three later contributions:

```text
Gates 10--13: compositional and one-step dynamic recovery
Gates 14--18: classical laws, independent semantics, and sound calculus
Gate 19: finite update traces, first loss, and recovery return.
```

No current manuscript claim is falsified by Gate 19. The principal risk is now
omission and accidental overgeneralization from one-step updates.

## Findings by priority

### High: one-step and finite-trace claims must be separated

The manuscript explicitly studies one-step conditionalization. Gate 19 does
not merely repeat that result for a list: its trace is dependent because every
later admissibility proof belongs to the posterior model generated by earlier
updates. A revision should state this dependency rather than quantify over an
unqualified list of evidence formulas.

### High: endpoint recovery is not pathwise preservation

The verified `T -> N -> T` witness shows that a recovered final state can hide
an intermediate loss of recovery. The paper should distinguish:

1. recovery in the final model;
2. recovery at every state of the trace;
3. first loss at a specific edge;
4. later return at a different edge.

Any phrase such as “recovery is preserved by the update sequence” must refer to
the second, stronger property.

### High: the exact preservation theorem has a guarded starting point

`RecoveryPreservedAlong iff NoDirectionalGapAlong` assumes that the formula is
recovered initially and that every model in the trace is probability-integrity
certified. After recovery is lost, the theorem cannot be restarted without
first proving a return condition. Gate 19 formalizes return separately through
recursive semantic classicality of the target model.

### Medium: the classical-semantics account remains stale

As already identified after Gate 17, the manuscript still stops at Gate 8's
model-induced split evaluator. A revision must separately present Gate 16's
independent model semantics, Gate 17's guarded equivalence, and Gate 18's sound
calculus. Completeness and decidability remain nonclaims.

## Recommended version-0.14 structure

1. Present Gates 10--13 as the one-step foundation: recursive recovery,
   fracture/restoration, directional gaps, and posterior probability integrity.
2. Add Gate 19 immediately afterward as the finite-trace lift, emphasizing
   dependent admissibility and the difference between endpoint and pathwise
   recovery.
3. Use the four-world `T -> N -> T` witness as the running finite-sequence
   example.
4. Present Gates 14--18 as a separate classical-boundary chain ending in
   soundness, not completeness.
5. Update the mechanization branch, module list, build count, and focused audit
   commands together with the manuscript version increment.

## Layout and build check

The current manuscript remains version 0.13 with 54 pages. Gate 19 changes no
TeX source; its integration should therefore be a deliberate version-0.14
revision followed by a fresh render and visual review, not a silent change to
the committed PDF.

## Editorial decision

Gate 19 is suitable for manuscript integration because it contributes both an
exact general theorem and a compact counterexample to endpoint reasoning. The
paper should avoid claiming bounds on the number of loss/return cycles,
product-update generality, infinite traces, or continuous-time behavior: none
of those extensions is proved by this gate.
