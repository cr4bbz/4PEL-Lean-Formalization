# Gate 3 — Circuits as Minimal Evidential Redundancy

## Question

For the coarse positive/negative partition matroid introduced in Gate 1, what are the minimal dependent evidence sets, and what does contraction mean epistemically?

## Main result

Let `polarity : α → EvidencePolarity`. Define `ChannelDependent polarity A` to mean that `A` contains two distinct atoms with the same polarity. Define `ChannelCircuit polarity C` as a dependent set whose every dependent subset already contains all of `C`.

Lean proves the exact classification

```text
ChannelCircuit polarity C
↔ ∃ x y,
    x ≠ y ∧
    polarity x = polarity y ∧
    ∀ z, C z ↔ EvidenceSet.pair x y z
```

Hence every circuit is exactly a distinct same-polarity pair.

## Closure formulation

Dependence is not merely a duplicate-counting definition. It is equivalent to the closure condition

```text
ChannelDependent polarity A
↔ ∃ x, A x ∧ channelClosure polarity (EvidenceSet.erase x A) x
```

So a dependent evidence body contains an atom already generated by the remainder.

## Minimal redundancy

If `x` and `y` have the same polarity, then

```text
channelClosure polarity {x,y}
=
channelClosure polarity {x}
```

pointwise. A two-element circuit therefore adds no new coarse generated channel beyond either retained representative. This is the precise Gate-3 meaning of *minimal evidential redundancy*.

The qualifier `coarse` matters: reliability, source identity, probability mass, causal provenance, and inferential route can distinguish atoms that the two-bit FDE projection treats as parallel.

## Circuit elimination

For pairwise-distinct `x y z` of one polarity, `{x,y}` and `{x,z}` are circuits and `{y,z}` is the elimination circuit after removing the shared element `x`. This is the two-channel partition instance of the standard matroid circuit-elimination pattern.

## Contraction probe

The repository's lightweight `MatroidClosure` currently has no explicit ground set, so Gate 3 does not pretend to provide a full minor API. Instead it defines the background closure

```text
channelClosureWithBackground polarity c A
:= channelClosure polarity (EvidenceSet.insert c A)
```

and proves:

- if `polarity c = polarity e`, then `e` is generated over empty new evidence;
- if `polarity c ≠ polarity e`, then `e` is not generated over empty new evidence.

This is exactly the closure phenomenon expected when contracting one member of a parallel class: its partners become loop-like. Epistemically, accepting one atom as fixed background makes additional same-channel atoms contribute no new coarse rank.

## Boundary discovered

Gate 3 exposes an important distinction:

- **deletion** should model source removal from the ground set;
- **contraction** should model quotienting/conditioning the structural problem by accepted background evidence.

A mathematically honest implementation of actual minors requires either extending `MatroidClosure` with an explicit ground set or bridging the project to a standard matroid API.

## Gate 4 candidate

Promote the lightweight closure layer to an explicit finite-ground-set matroid interface and prove genuine deletion/contraction theorems. The first target should be the partition-matroid fact that contracting one evidence atom turns every remaining same-polarity atom into a loop while leaving the opposite channel nonlooping.
