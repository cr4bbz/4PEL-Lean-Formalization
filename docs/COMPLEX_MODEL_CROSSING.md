# Complex Strong-Model Crossing Classification

Status: **VERIFIED**

## Scope

`PEL4/ComplexModelCrossing.lean` lifts affine threshold-crossing geometry to
complete `StrongProbabilityModel` paths for probability-free modal formulas.
It composes the affine complex coordinate from `ComplexModelPath.lean` with
the unique crossing and intermediate-phase results.

## Main chain

For two weight-generated strong endpoint models on a common semantic skeleton:

```text
ModalProbabilityFree phi
-> z_phi(t) = (1-t) z_phi(0) + t z_phi(1)
-> a two-wall endpoint change makes both coordinates straddle c
-> unique positive and negative crossing times tp and tn
-> the hits occur at actual complete intermediate models
-> positive-first, simultaneous, or negative-first classification.
```

The main theorem is:

```text
convexStrongModelPath_probabilityFree_complete_crossing_classification
```

## Three model-realized cases

```text
tp < tn
-> the rational crossing midpoint lies in [0,1]
-> its complete model has the positive-first adjacent FDE phase

tp = tn
-> the complete model at the common time has z_phi = (c,c)
-> inclusive thresholding gives bel i phi = B

tn < tp
-> the rational crossing midpoint lies in [0,1]
-> its complete model has the negative-first adjacent FDE phase.
```

The simultaneous case has no open interval carrying an adjacent intermediate
phase, but it does contain one distinguished complete boundary model.

## Remaining boundaries

- Formulas containing probabilistic belief may change their own support events
  along the probability path.
- A valid convex model path is not yet proved to be generated by repeated
  admissible conditionalization of its source.
- Uniqueness of crossing times is specific to affine nonconstant coordinates;
  arbitrary continuous paths require a richer crossing theory.
