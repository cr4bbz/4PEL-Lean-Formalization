# Matroid Evidence Gate 2: Topological Exchange Boundary

Status: research branch `research/matroid-topological-gate2`

## Research question

When does the closure operator already used by the topological 4-PEL evidence
semantics also satisfy the exchange axiom from the Gate-1 matroid layer?

The answer is exact at the closure level formalized in this repository.

## Main characterization

Let `cl` be the closure induced by an `InteriorSemantics`. Because this closure
preserves binary unions,

```text
cl(A ∪ {y}) = cl(A) ∪ cl({y}).
```

Therefore the Mac Lane--Steinitz exchange condition

```text
x ∈ cl(A ∪ {y}) and x ∉ cl(A)
=> y ∈ cl(A ∪ {x})
```

is equivalent to the two-point condition

```text
x ∈ cl({y}) => y ∈ cl({x}).
```

The Lean theorem is:

```text
topologicalClosureExchange_iff_r0Like
```

For an ordinary topological space, `x ∈ cl({y})` is the specialization
relation. Symmetry of that relation is the standard `R0` separation condition.
The repository names the algebraic condition `TopologicalR0Like` because
`InteriorSemantics` deliberately avoids importing a full point-set-topology
library.

## Sierpinski obstruction

The existing two-point Sierpinski witness is asymmetric:

```text
focus ∈ cl({neighbour})
neighbour ∉ cl({focus}).
```

Hence it fails `TopologicalR0Like`, and therefore its closure fails matroid
exchange. This gives a countermodel internal to the existing 4-PEL topological
research line rather than an unrelated external example.

Lean declarations:

```text
sierpinski_focus_specializes_neighbour
sierpinski_neighbour_not_specializes_focus
sierpinski_not_topologicalR0Like
sierpinski_not_topologicalClosureExchange
```

## Compatibility with Gate 1

Gate 1's coarse positive/negative channel matroid is not merely compatible with
some topology. It has a canonical partition topology. Define the interior of a
region `A` by requiring the whole polarity class of a point to lie inside `A`:

```text
channelInterior polarity A e :=
  forall a, polarity a = polarity e -> A a
```

Its dual topological closure is exactly `channelClosure`. Thus the two Gate-1
parallel classes are precisely the specialization-equivalence classes of this
partition topology.

Lean declarations:

```text
channelInteriorSemantics
channelInteriorSemantics_closure_iff_channelClosure
channelInteriorSemantics_r0Like
channelInteriorSemantics_exchange
```

## Structural interpretation

Gate 2 separates two notions that looked superficially similar in Gate 1:

- topological closure records approximation / boundary reachability;
- matroid closure records dependence with exchangeability of new generators.

A topological boundary can be directional. A matroid dependency generated by
singleton closure cannot be directional once exchange is imposed. The R0-like
condition is therefore the exact boundary between these two behaviours in the
repository's topological closure semantics.

For genuine point-set topologies this yields the familiar consequence that a
`T0` topology satisfying the exchange boundary is `T1`: once specialization is
both antisymmetric (`T0`) and symmetric (`R0`), distinct points cannot lie in
one another's singleton closures.

## Scope boundary

`MatroidClosure` in Gate 1 is a lightweight closure-axiom presentation. It does
not currently include a finite-character axiom. The results here therefore
establish matroidality in exactly that repository-level closure sense. On finite
state spaces, which include the explicit 4-PEL witnesses, finite character is
automatic. An infinite-carrier finitarity theorem is a separate extension.
